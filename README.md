# PHP Easy 🚀

A PHP-based learning and practice platform.

## Features (current)

- Admin Authentication (Login / Logout)
- Middleware-based route protection
- Topic Management (Add / Update / View / Soft Delete)

## Tech Stack

- **FRONTEND:** HTML, CSS, Vanilla JavaScript
- **BACKEND:** Vanilla PHP (w' OOPS)
- **DATABASE:** MySQL
- **SOFTWARE:** Laragon
